# EasyColab Project Overview

- **Backend**: `app.py` (Gradio + FastAPI `/minimax_api/*`, ComfyUI launcher/tunnel/preset manager, multi-model VRAM & Drive persistence) + `EasyColab_Server.ipynb` (Cell 5 mirrors `app.py` byte-for-byte) + `colab_bridge.py` + `runtime_auth.py`
- **Clients**:
  - macOS: `macos_app/` (SwiftUI)
  - Windows / Linux: `windows_app/` (PySide6 / Qt6)
  - iOS / iPadOS: `ios_app/` (SwiftUI)
  - Android: `android_app/` (Kotlin Jetpack Compose)
- **Tests**: `tests/` (`unittest` suite; note `test_comfy_h3_optimizations.py` runs standalone without `google_auth_oauthlib`)
- **Verification**:
  - `python3 -m py_compile app.py windows_app/models.py tests/test_comfy_h3_optimizations.py`
  - `python3 -m unittest tests/test_comfy_h3_optimizations.py -v`
  - `swiftc -parse macos_app/Sources/ModelsAndCatalogs.swift ios_app/Sources/LocalizationAndModels.swift`
